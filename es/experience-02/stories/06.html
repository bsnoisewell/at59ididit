AT 59, I DID IT WITH AI. EXPERIENCIA #02 · LIBRO #02

6.
El humano imagina. ChatGPT planifica. Codex construye.

Conocí Codex

mientras creaba mi primer sitio web.

Al principio,

lo incorporé a mitad del proceso.

Hablaba durante un buen rato con ChatGPT

y, cuando necesitaba código,

se lo pasaba a Codex.

Esta vez,

dividí los papeles con un poco más de claridad.

Primero,

imaginé todo con suficiente detalle.

El sueño de un bebé,

los personajes,

el ambiente...

«Un bebé que se queda dormido entre las nubes

junto a un personaje,

escuchando una canción de cuna.»

Con esa idea,

empecé a planificarlo con ChatGPT.

Planificamos los personajes,

las canciones de cuna,

el ruido para ayudar a dormir

y cómo mezclarlo todo.

Hacer que las estrellas parpadearan.

Que cayeran estrellas fugaces.

Que la imagen se fuera oscureciendo poco a poco.

Y, al mismo tiempo,

que el sonido fuera bajando poco a poco.

Seguí consultando con ChatGPT

si cada parte del plan era posible.

Si algo no se podía hacer,

buscábamos una forma de hacerlo posible.

Y cuando terminamos de planificarlo todo,

llamé a Codex.

Yo ya había creado un sitio web una vez.

Sabía que,

llegados a este punto,

podía terminarlo en una semana.

Con el primer sitio,

había ido dando tumbos.

Esta vez era diferente.

El humano imagina.

ChatGPT planifica.

Codex construye.

Ahora ya éramos un equipo.
