In the AI Era, Ideas Go Further. Why Not Put Everything in One Excel File?

The website was getting more complicated.

Each character had a name.

A description.

An image.

A lullaby.

Noise.

Settings.

And all of these were scattered across different files.

If I wanted to change one thing, I had to find where it was.

I don't like working that way.

I want to see everything at a glance.

So I asked AI.

"Can't we just put all of this into one Excel file?"

Character names, descriptions, music file names, settings — all organized in one Excel file.

Then AI could convert what I'd organized in Excel into a format the website could use.

Wouldn't that work?

AI said it was possible.

Huh?

Manage everything based on the Excel file,

then use a program to convert it into website data whenever needed.

I only have to look at the Excel file.

Suddenly, everything that had seemed complicated became simple.

In the past, I probably would have thought I needed to learn how websites were supposed to be built.

This time, I thought about it the other way around.

Why can't the website adapt to the way I work?

Done.
