2.
Ich weiß gar nichts. Geht das trotzdem?

Ich wusste,

dass es schwierig sein sollte, eine Website zu erstellen.

Und es schien ziemlich viel zu tun zu geben.

Eine Domain kaufen.

Bilder erstellen.

Programmieren.

Einen Server einrichten.

Die Website für Computer und Smartphone anpassen.

Den Server verbinden.

...

Dass ich das alles allein machen könnte,

hatte ich mir nie vorstellen können.

Ich hatte nie Design gelernt.

Vom Programmieren verstand ich noch weniger.

Ich wusste nicht einmal,

wo sich so ein Server überhaupt befindet.

„Ich weiß gar nichts darüber.

Und ich bin allein.

Geht das trotzdem?“

Die KI antwortete:

„Ja. Sie können das auch allein schaffen.“

Ich starrte einen Moment auf den Bildschirm.

„Hm ... Das geht wirklich?“

Ich war nicht überzeugt.

„Moment mal.

Soweit ich weiß, muss man dafür doch unglaublich viel machen.

Bilder, Programmieren, den Server verbinden, eine Domain kaufen ...

Du willst mir sagen,

dass du mir bei all dem helfen kannst?“

„Ja.“

„Und was muss ich dann machen?“

„Sie müssen nur entscheiden, was für eine Website Sie erstellen möchten, Captain.“

Ich hatte immer noch Zweifel.

Und so begann ich,

meine erste Website zu bauen.
